# ColorFlow-Web 开发计划

> 版本：1.0 · 2026-09-04 · 基于 Sprint 1-3 交付状态

## 项目总览

**ColorFlow-Web**：AI 矢量描图 + Pantone 色彩管理 + 印刷报价的 Web 应用，通过 MCP Server 接入 AI Agent。

**红线**（贯穿所有阶段）：
1. AI 生图必须经抠图（CUTOUT）后才能描图
2. 仅使用商用许可模型（排除 BRIA/RMBG）
3. API Key 仅存服务端环境变量，不进前端
4. 零本地 GPU（云端 API 生图/抠图，本地仅 CPU 级格式转码）
5. 失败可降级，绝不假成功
